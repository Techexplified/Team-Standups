Trello Power-Up Architecture

This project is structured specifically for Trello's multi-page iframe architecture and secure member-private OAuth token lifecycle.

1. Multi-Page Entrypoints

powerup.html -> TrelloPowerUp.initialize capabilities connector auth.html -> Popup window for member authorization authorized.html-> OAuth redirect target (posts token & closes) settings.html -> Power-Up settings dialog in board menu standup.html -> Main modal dashboard & card-back section

2. Secure OAuth Flow

1. User opens auth.html inside Trello popup.
2. Popup opens Trello authorization URL with return URL pointing to authorized.html.
3. Member authorizes access; Trello redirects to authorized.html#token=....
4. authorized.js reads token from URL hash, cleans history, and emits window.opener.postMessage.
5. AuthPopup.jsx stores the token in Trello member-scoped private storage via t.set('member', 'private', 'token', token).

3. Trello Developer Registration

To register this Power-Up in Trello: Go to trello.com/power-ups/admin, create a Power-Up, and configure the Iframe connector URL to your deployed powerup.html.
